# Remote Pi 1.9.2

## What's new

- **The session picker shows each session by its own name.** A conversation
  that has been given a name — set in the Pi with `/name`, chosen by the agent,
  or pinned when the room was started — now appears under that name instead of
  its first line, so a list of conversations is told apart by what they are
  about rather than by whatever the opening message happened to be. Sessions
  that never named themselves still show their first message, and the
  folder-default name is still ignored, so a room never fills up with identical
  rows.
